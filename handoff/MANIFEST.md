# Handoff archive manifest

The migration archive contains:

- the TV mode source tree without `.git` and cache files;
- the handoff and installation documents;
- a Polish clean-system quick start in `handoff/START_HERE_PL.md`;
- selected system documentation from `.docs`;
- the action log and daily work history from `.docs`;
- Steam artwork, if it exists on the source system.

The archive does not contain:

- browser profiles or cookies;
- passwords, tokens, or authentication files;
- screenshots;
- Git credentials;
- system logs;
- the raw chat transcript, which is not available as a local file;
- the repository `.git` directory.

The Git repository is the primary source. The archive is an offline fallback.
Copy it away from the disk before replacement and verify its SHA-256 file.
