# TV mode documentation

## Documents

- `INSTALL.md` explains installation and removal.
- `STEAMOS.md` explains a clean SteamOS installation.
- `DECKY_PLAN.md` evaluates a future Decky Loader interface.
- `SERVICE_AUDIT.md` records controller and scaling behavior.
- The root `README.md` explains the project and its files.
- `../handoff/HANDOFF.md` contains the project handoff.

## Writing rules

The documentation uses ASD-STE100 style:

- Use short sentences.
- Use one instruction for each step.
- Use common words.
- Use the same term for the same function.
- Explain an abbreviation before use.
- Do not hide required actions in long paragraphs.

The documentation does not include passwords, tokens, or private browser data.
